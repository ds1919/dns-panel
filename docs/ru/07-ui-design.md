# 07 — UI / дизайн

UI на английском. Интерфейс строится вокруг задач оператора, а не вокруг таблиц БД.

## Лейаут

- **Слева — сайдбар** (`header.pl`): `Dashboard · Zones · Labels · Propagation · NS Pulse · High availability ·
  Audit log · Settings`; внизу — пользователь (ссылка на Account). Records — не пункт меню: записи
  открываются на странице зоны.
- **Top bar** — только глобальный поиск по имени или IP (`js/search.js`, `GET /dns-api/records/search`).
- **Баннер STANDBY** под top bar — на узле пары без сервисного адреса: правки здесь отклоняются, работать
  надо на сервисном адресе.
- Основной контент — единственный `<main id="main-content">`.

## Страницы

- **Zones** — таблица зон с общим компонентом фильтров; Add zone — модалкой.
- **Страница зоны** (`/records?zone=<id>`) — SOA и apex NS в аккордеоне, ниже таблица RRset; Zone settings
  (роль, Dynamic updates, раздача) и DNSSEC — модалками со страницы зоны.
- **Settings** — вкладки `Zone profiles · Import · Dynamic DHCP profiles · Pinger & Pulse · Users & access`,
  видимые по правам. Новая вкладка добавляется в `availTabs()` **и** в белый список `initTab()` (`js/settings.js`).

## Палитра и темы

По умолчанию — нейтральная тёмно-серая тема (`:root` в `css/main.css`): грейскейл-фон и хром, приглушённый
teal-акцент (`--accent: #4bb3a5`) точечно — активный пункт, primary-кнопка, статус.

Темы — `css/themes/*.css`, выбираются в Account (`@THEMES` в `functions.pm`; пусто = как в браузере,
`auto.css`). Тема переопределяет **только CSS-переменные** (цвета, `--font-ui`, `--bg-pattern`), не лейаут.
Компоненты не хардкодят цвета — только `var(--…)`. Ссылку на тему вставляет сервер, чтобы не было
вспышки чужой темы.

## Правила компонентов

- **Контролы стилизованы один раз, по тегу** (`input`, `textarea`, `select`, кнопки — в `main.css`).
  Классы — только для вариантов (размер, ширина, поведение). Страничный CSS не перекрашивает стандартные
  элементы, он задаёт только геометрию.
- Выпадающие списки — `DNSPanel.selectHtml` (`.ui-select`, меню в теме панели, а не нативный popup).
- Диалоги — общие модалки (`#modal-overlay`, `DNSPanel.dialog`/`confirm`): модалка держит контекст
  страницы. Drawer'ов нет.
- Контрол внутри таблицы — высотой в строку текста: переход read → edit не меняет высоту строки.
- Тонкие границы (1px), скругления 8–10px, плотные таблицы, hover без ярких подсветок.
- Шрифт системный (`system-ui` и далее по стеку); внешних зависимостей (шрифты, CDN) у `www/` нет.
